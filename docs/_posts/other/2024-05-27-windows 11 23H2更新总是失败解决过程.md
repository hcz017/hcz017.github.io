# 频繁更新失败的困扰

最近一个月以来 windows 11 系统 23H2 **更新总是失败**，更新失败会撤销更改:

![](https://img-blog.csdnimg.cn/img_convert/d4260d89df536fefe8ceca51b3ab3005.jpeg)

之后会自动重启系统，但是**重启进不去系统**，屏幕有背光但是不显示任何内容。这时候只能长按开机键强制关机。每次出现这种情况我都没办法远程连接到此电脑工作，只有等到亲自来到电脑前来一次强制关机再开机。
网上查了一下方法，有人遇到重启总是失败的问题，但是没有可靠的解决办法。按照微软官方的建议，考虑下载 “MediaCreationTool_Win11_23H2” 升级，但是遇到了 "**抱歉，我们在确定你的电脑能否运行windows11时遇到问题**”

![](https://img-blog.csdnimg.cn/img_convert/6d83bde7d3467b8e9af793594bbe3b19.png)

# “殊途同归”的解决办法

庆幸的是按照这个错误提示我找到了另一个资料 [抱歉,我们在确定你的电脑能否运行windows11时遇到问题](https://tieba.baidu.com/p/7627723324)，在12楼有人提出**用DiskGenius检查一下系统盘有没有ESP分区，如果没有的话新建 ESP 分区解决此问题**。
我用 DiskGenius 检查了确认没有  ESP 分区，于是新建了一个。（下图为新建ESP 之后的截图）

![](https://img-blog.csdnimg.cn/img_convert/b07d839aae4c45170549e6be419526a9.png)

之后再次尝试系统更新，等待了漫长的十几分钟后重启更新，这次更新成功了，但是更新之后的重启又进不去系统了，这次是**引导问题**

![](https://codesimple-blog-images.oss-cn-hangzhou.aliyuncs.com/other/_image/windows_boot_manager_error.JPG)

简单试了一下选择从硬盘引导是可以正常进入系统的，且确实更新到了23H2。不知道是不是因为我之前有一个 boot 分区里面已经有了 EIF 启动信息，现在新搞了一份导致 windows boot manager 引导错误。

![](https://codesimple-blog-images.oss-cn-hangzhou.aliyuncs.com/other/_image/windows_boot_esp_eif.png)

使用 DISM++ 修复引导后这个问题修复了，一切恢复正常。
